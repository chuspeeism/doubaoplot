# 这些图表本 skill 没有绘图路线

用户点名要下面任何一种图时，**直接说清楚「Origin 本身画得出来，但这个 skill 没写对应的绘图路线」，
不要硬试**。硬试的结果是跑一遍失败，浪费用户几分钟，还会让人以为是自己数据的问题。

说完之后可以做两件有用的事：

1. 如果用户的意图能用已有路线近似表达，主动提出来（比如 PCA / t-SNE / UMAP 的坐标只要已经算好，
   就能用 `scatter` 路线画成分组散点）。
2. 否则请用户自己在 Origin 里画，或者去上游仓库提需求。

## 几个特别容易被问到的

- **生存曲线 / Kaplan-Meier** —— 医学论文里出现频率最高的图之一，但本 skill 的医学组里
  做了 ROC、PR、DCA、校准曲线、混淆矩阵、Bland–Altman，唯独没有 KM。被问到时说清楚，别绕。
- **PCA / t-SNE / UMAP** —— 严格说不在这张表里（它们能用 `scatter` 近似），但要提醒用户：
  降维坐标必须自己先算好，本 skill 只负责把算好的坐标画成分组散点，不替你降维。
- **3D 曲面、体绘、切片、矢量场、等值面、条形** —— 三维那一族基本没覆盖，只有
  `density_ridgeline3d`（三维双密度曲线）和 `trajectory3d`（三维 Nyquist 轨迹）两条真路线。
